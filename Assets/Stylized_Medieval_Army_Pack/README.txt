This pack was created as a modular stylized medieval army system inspired by historical references rather than fantasy themes. The assets are designed to be easy to customize and integrate into different types of game projects.

---

# CHARACTER CUSTOMIZATION

Characters are built using modular parts.

To change the appearance of a character:

* Replace meshes inside the Skinned Mesh Renderer components.
* Helmets, outfits, accessories, and addons can all be swapped this way.

Faction colors are controlled through materials.
The models use a stylized color palette workflow based on UV-painted 32x32 textures.

To change faction colors:

* Assign a different material to the mesh renderer.
* Materials contain different faction color variations.

---

# ADDING MORE ADDONS

Additional armor pieces and accessories can easily be added.

To create more addon variations:

* Duplicate an existing addon object.
* Replace the mesh with another compatible mesh.
* Assign the desired material if needed.

---

# IMPORTANT NOTE ABOUT RIGGING

This pack uses low poly stylized topology.

Characters are compatible with standard humanoid workflows and common animation systems such as Mixamo. However, due to the low poly nature of the models, minor deformation artifacts may appear in extreme poses.

If you are new to modular character systems, I highly recommend learning how Skinned Mesh Renderers work in Unity to avoid unnecessary frustration during customization and animation setup.
