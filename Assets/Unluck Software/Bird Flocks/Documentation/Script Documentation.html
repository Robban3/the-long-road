Introduction

The Bird Flock Asset is a Unity flocking system by Unluck Software that simulates realistic bird behavior - roaming, soaring, diving, collision avoidance, landing, and takeoff. All runtime scripts live in the UnluckSoftware namespace (except a few utility addons).

The system is built around a central FlockController that spawns and manages many FlockChild bird instances. Optional LandingSpotController / LandingSpot components add perching behavior. Animation is supported via legacy Animation, Mecanim Animator, or baked mesh animation (BakedMeshAnimator).

This page combines the original PDF user guide with detailed script reference documentation.

Quick Start

  1. Create an empty GameObject and attach FlockController.
  2. Assign a bird prefab with FlockChild on it to Bird Prefab (_childPrefab).
  3. On the bird prefab, ensure a child named Model exists and references are filled (use the Click Me! button in the FlockChild inspector).
  4. Set animation clip names on the FlockController: Flap, Soar, and Idle (or your clip names).
  5. Adjust flock size (_childAmount), roaming area (_positionSphere dimensions), and speed ranges.
  6. Press Play - birds spawn and roam within the spawn sphere around the controller's position buffer.

Optional: Landing Spots

  1. Create a GameObject with LandingSpotController and assign the FlockController.
  2. Add child GameObjects, each with a LandingSpot component (orient the spot's forward/up for takeoff direction).
  3. Configure auto-catch and auto-dismount delays. Birds within range will land, idle, then fly away.
Tip Scene gizmos on FlockController show the spawn box (gray) and roaming area (dark). LandingSpot gizmos show detection radii and approach waypoints when enabled.

Custom Bird Prefab

Create a new bird prefab using a custom bird model.

  1. Make sure the custom model uses the Legacy animation system. (version 3.0+ also allows Generic)
  2. Drag the custom model to the scene.
  3. Duplicate an existing Bird prefab in the project.
  4. Drag the new prefab to the scene.
  5. Drag the custom model in the scene into the bird GameObject.
  6. Adjust scale, rotation, and position so that it aligns with the current bird.
  7. Configure animations of the custom model.
  8. Delete the old model.
  9. Rename the custom model to Model.
  10. Click Apply in the Inspector to save changes.
  11. Drag the new prefab into the desired Bird Flock Bird Prefab property.

Free Moving Flock

A flock that can be moved around in the scene.

  1. Set the roaming area to 0, 0, 0 so that only the flock box is visible.
  2. Disable Group to Flock. Birds will no longer be parented as child objects to the flock GameObject.
  3. Set Automatic Flock Waypoint to 1. The flock will follow its new position faster.
  4. Enable Force Bird Waypoints. Birds also change direction when the flock has been moved.

Baked Birds

Use a series of regular meshes instead of a skinned mesh to improve performance, at the cost of crossfading. See the example scenes and prefabs in the Baked (performance) folder.

Bird prefabs with baked animations can be used in any previously made flock. To create custom baked animations, use the SkinnedMesh Baker tool on the Asset Store.

FlockController Core

FlockController.cs · namespace UnluckSoftware · Requires FlockChild prefab

The root manager for the flock. Instantiates bird prefabs, maintains the list of active roamers, periodically repositions the flock center, and exposes global movement, animation, and avoidance settings.

Key Responsibilities

  • Spawn birds via AddChild(int) and remove via RemoveChild(int)
  • Keep live bird count in sync with _childAmount at runtime
  • Move flock waypoint volume with SetFlockRandomPosition() on a repeating timer
  • Optionally group spawned birds under a new transform or the controller itself
  • Draw spawn/roaming gizmos in the Scene view

Inspector Groups

Category Key Fields Description
Flock Properties _childPrefab, _childAmount, _spawnSphere* Prefab, count, and local spawn volume dimensions
Roaming Area _positionSphere*, _randomPositionTimer World-space volume the flock center moves within
Speed & Scale _minSpeed, _maxSpeed, _minAcceleration, _maxAcceleration, _minScale, _maxScale Per-bird random ranges applied on spawn
Behavior _soarFrequency, _diveFrequency, _diveValue, _waypointDistance Flight mode probabilities and steering
Rotation _minDamping, _maxDamping, _flatFly, _flatSoar, _birdRoll Turn smoothing and banking
Animations _flapAnimation, _soarAnimation, _idleAnimation, _minAnimationSpeed, _maxAnimationSpeed Clip names and speed ranges
Avoidance _birdAvoid, _birdAvoidHorizontalForce, _avoidanceMask Raycast-based obstacle steering

FlockChild Core

FlockChild.cs · Attached to each bird prefab

Individual bird agent. Steers toward waypoints, switches between flap/soar/dive modes, performs collision avoidance, and handles the full landing sequence when assigned to a LandingSpot.

Flight Modes

Mode Trigger Behavior
Flap Default / after soar timeout Random waypoint in spawn sphere; flap animation
Soar _soarFrequency random check Only if waypoint is below bird; glide animation
Dive _diveFrequency random check Waypoint drops by _diveValue; uses soar animation
Landing Assigned by LandingSpot Approach, snap, idle; controlled by landing controller modifiers

Important Fields

_modelAnimation / _animator Legacy Animation or Mecanim Animator on the model
_landingOffsetFix Vertical offset so feet touch ground (scale-aware)
_landingPosOffset Per-bird landing position offset on the spot

Collision Avoidance

When _birdAvoid is enabled on the controller, each bird casts rays forward-left and forward-right (and optionally up/down). Hits on _avoidanceMask layers cause yaw/pitch adjustments. Avoidance is disabled near landing spots within _disableLandingAvoidanceDistance.

LandingSpotController Core

LandingSpotController.cs · Parent of LandingSpot children

Coordinates all landing spots under its transform. References a FlockController to pull birds from, and exposes global landing timing, movement modifiers, and batch operations.

LandingSpot Core

LandingSpot.cs · One per perch / branch / wire

A single landing target. Periodically searches the flock for an eligible bird, assigns it, manages the landing lifecycle, and releases the bird after the configured idle period.

Landing Lifecycle

  1. Catch - GetFlockChild() coroutine finds a bird within min/max distance
  2. Approach - Bird steers to spot; optional _preLandWaypoint for curved approaches
  3. Land - Speed reduced; animation transitions to Idle; position snapped
  4. Idle - Bird sits until auto-dismount timer or external scare
  5. Release - ReleaseFlockChild() emits feathers, flaps away, pauses re-landing for 5 s

Public Methods

Method Description
GetFlockChild(float minDelay, float maxDelay) Coroutine - wait then attempt to catch a bird
InstantLand() Immediately assign and idle the first available bird
Landed() Called by FlockChild when snap landing completes
ReleaseFlockChild() Force bird to take off from this spot

FlockScare Core

FlockScare.cs · Attach to player, camera, or trigger object

Periodically scans assigned LandingSpotController instances. When this transform is within distanceToScare of an occupied landing spot, it either scares all birds on that controller or releases only the nearby bird.

Field Description
landingSpotControllers Array of controllers to monitor
scareInterval Seconds between proximity checks (default 0.1)
distanceToScare Scare radius around this object
checkEveryNthLandingSpot Skip spots for faster scanning across many controllers
InvokeAmounts Parallel coroutines for large controller counts
scareAll true = ScareAll() on controller; false = single spot release

FlockChildSound Core

FlockChildSound.cs · Requires AudioSource + FlockChild on same GameObject

Plays randomized idle and flight sounds while the bird is active. Plays scare sounds when a previously landed bird takes off again.

Field Description
_idleSounds / _flightSounds / _scareSounds Clip pools for each state
_idleSoundRandomChance / _flightSoundRandomChance Per-second probability of playing (default 0.05)
_pitchMin / _pitchMax Random pitch range (0.85–1.0)
_volumeMin / _volumeMax Random volume range (0.6–0.8)

FlockWaypointTrigger Core

FlockWaypointTrigger.cs · Optional child of a bird

Invokes FlockChild.Wander(0) on a repeating random timer. Useful for forcing periodic direction changes independent of waypoint distance. Auto-finds FlockChild on the parent if not assigned.

Addon Scripts Addons

RandomMaterial
Addons/RandomMaterial.cs

On Start, assigns a random material from materials[] to targetRenderer. Call ChangeMaterial() to re-randomize.

BirdMaterialChanger
Addons/BirdMaterialChanger.cs

Assigns materials sequentially from materials[] to the first SkinnedMeshRenderer in children, using a static counter so each spawned bird gets the next material in the array.

UnluckDistanceDisabler
Addons/UnluckDistanceDisabler.cs

Performance utility. Disables the GameObject when farther than _distanceDisable from a reference transform (or main camera). Re-enables when back in range. Uses separate check intervals for disable (10 s default) and enable (1 s default).

Field Description
_distanceDisable Distance threshold in world units (default 1000)
_distanceFromMainCam Use Camera.main as reference
_disableOnStart Start disabled if out of range

Public API Summary

Common calls for gameplay integration:

// Flock management

flockController.RemoveChild(5);
flockController.destroyBirds();

// Landing control
landingSpotController.ScareAll();
landingSpotController.LandAll();

// Per-spot control
landingSpot.ReleaseFlockChild();

// Per-bird control
flockChild.Flap();
flockChild.Soar();
flockChild.Wander();
flockChild.PauseLanding(5f);

Performance Tips

  • Skip Frame - Enable _skipFrame on FlockController to update half the birds per frame.
  • Bird count - Reduce _childAmount or use the demo slider to find your target FPS.
  • Distance culling - Attach UnluckDistanceDisabler to the flock root or controller; disable distant flocks entirely.
  • Avoidance - Raycasts per bird per frame are expensive. Disable _birdAvoid or narrow _avoidanceMask if not needed.
  • Grouping - Use _groupChildToNewTransform to keep the hierarchy tidy; no direct performance gain but easier to toggle entire flocks.
  • Baked animation - The baked mesh path (BakedMeshAnimator) avoids skinning overhead for large flocks.
  • FlockScare scanning - Increase checkEveryNthLandingSpot and tune InvokeAmounts when monitoring many controllers.
